# Shadow Runner - Endless Roguelike

A mobile-first 2D endless runner roguelike game that runs in iPhone Safari via GitHub Pages.

## 🎮 Play Now

Open the GitHub Pages URL in your mobile browser to play!

## 🕹️ Controls

| Action | Control |
|--------|---------|
| **Jump** | Tap anywhere or swipe up |
| **Slide** | Swipe down |
| **Move Left** | Swipe left |
| **Move Right** | Swipe right |

## ✨ Features

- **Mobile-First Design**: Optimized for iPhone Safari with touch controls
- **3-Lane Gameplay**: Switch between lanes to avoid obstacles
- **Roguelike Progression**: Collect coins to unlock permanent upgrades
- **Power-ups**: Shield, Coin Magnet, and Score Multiplier
- **Responsive**: Works on all screen sizes

## 🚀 Upgrades

- **Higher Jump**: Jump higher to clear obstacles
- **Coin Magnet**: Attract coins from further away
- **Shield Duration**: Shields last longer
- **Score Bonus**: Start with a higher score multiplier
- **Head Start**: Start further ahead each run

## 🛠️ Technical Details

- Pure HTML5, CSS3, and vanilla JavaScript
- No external dependencies
- Canvas-based rendering
- Touch gesture recognition
- Local storage for save data
- 60 FPS gameplay

## 📱 Browser Support

- iOS Safari ✅
- Chrome (Mobile/Desktop) ✅
- Firefox ✅

## 🎯 How to Play

1. Tap "TAP TO RUN" to start
2. Avoid obstacles by jumping (tap) or sliding (swipe down)
3. Switch lanes with left/right swipes
4. Collect coins (gold circles)
5. Grab power-ups (green boxes) for special abilities
6. When you crash, spend coins on upgrades
7. Try to beat your high score!
